Luxe Éclat shop app
A mobile shopping app for candles

Techs used: 
react native
supabase
react navigation
asyncstorage

Features:
Feature 1  — Login and register with Supabase Auth
Feature 2  — Products fetched from Supabase with filters
Feature 3  — Upload product photos to Supabase Storage
Feature 4  — Barcode scanner to find products
Feature 5  — Cart with add, remove, quantity — saved with AsyncStorage
Feature 6  — Push notification when order is placed
Feature 7  — Map showing nearby stores using GPS
Feature 8  — Offline mode — products load from cache with no internet
Feature 9  — PDF receipt generated after every order
Feature 10 — Checkout form with order saved to Supabase
Feature 11 — Banner appears when phone goes offline
Feature 12 — App stops syncing when battery is below 20%
Feature 13 — Order history with pagination and full order details
Feature 14 — Wishlist saved to Supabase database
Feature 15 — Haptic feedback on cart and checkout actions
Feature 16 — Deep linking to open specific screens from a URL
Feature 17 — Realtime stock updates using Supabase channels
Feature 18 — Currency and language based on device locale
Feature 19 — Dark and light mode with a toggle in Profile
